# Сайт BST Phuket

Продающий сайт о наружной рекламе на Пхукете: главная и семь страниц услуг на трёх языках (русский, английский, тайский).

Адрес показа: https://a1exxx.github.io/bst-phuket-site/

## Как устроено

| Что | Где лежит |
|---|---|
| Тексты страниц | `content/ru.mjs`, `content/en.mjs`, `content/th.mjs` |
| Телефон, мессенджеры, соцсети, карта, счётчик рекламы | `site.config.mjs` |
| Оформление | `src/site.css` |
| Поведение страниц (вывеска, заявка, меню) | `src/site.js` |
| Эффекты: лучи света, электрическая рамка, объёмные плитки | `src/fx.js` |
| 3D-модель буквы | `src/scene3d.js` |
| «Умный билборд» на первом экране: слова, по которым угадывается бизнес, и примеры рекламы | `content/board.mjs`, картинки `src/img/b-*.webp` |
| Помощник-бот в углу сайта: вопросы, ответы, передача в мессенджер | `content/assistant.mjs`, `src/assistant.js`, `src/assistant.css` |
| Сборщик страниц | `build.mjs` |
| Готовый сайт (его показывает GitHub) | папка `docs/` |

## Как поменять текст или контакты

1. Исправить текст в `content/…` (во всех трёх языках) или контакт в `site.config.mjs`.
2. Собрать сайт: `node build.mjs`
3. Проверить: `node check.mjs` — должно ответить `OK`. Проверка ловит несовпадение языков, пустые переводы и ссылки в никуда.
4. Отправить на GitHub: `git add -A`, `git commit -m "что изменили"`, `git push`. Через минуту-две сайт обновится.

Посмотреть на своём компьютере до отправки: `python -m http.server 8761 --directory docs` и открыть http://localhost:8761

## Как работает заявка

Формы с отправкой на сервер нет. Человек отмечает, что ему нужно, и нажимает «Отправить в WhatsApp» — открывается чат с BST, текст заявки уже вписан. Для Telegram и LINE текст копируется, остаётся вставить его в чат.

## Как работает помощник-бот

В углу сайта кнопка «Помощник». Бот отвечает сразу по готовым ответам: узнаёт тему по словам в вопросе (вывеска, буквы, LED, робот, цена, сроки, монтаж, адрес), отвечает и предлагает передать разговор менеджеру в Telegram или WhatsApp — с готовым текстом заявки. Цен и сроков бот не называет: их заказчик не давал.

Это не нейросеть. Чтобы бот отвечал своими словами, нужен небольшой сервер с нейросетью; его адрес вписывается в `assistUrl` в `site.config.mjs` — сайт менять не придётся.

## Как работает «умный билборд»

Человек вписывает название на первом экране. Сайт ищет в названии знакомое слово (bar, кофе, массаж, yoga, вилла…) и дорисовывает на вывеске пример рекламы: картинку и строку вроде «Пробный урок бесплатно». Слово не найдено — остаётся жёлтая вывеска с названием. Список слов и строк — в `content/board.mjs`.

## Что включается одной строкой в `site.config.mjs`

- `metaPixelId` — счётчик Meta для рекламы. Пока пусто: счётчик не загружается.
- `line` — ссылка на LINE. Пока пусто: кнопка показывает номер телефона.
- `tiktok` — ссылка на TikTok. Пока пусто: значок скрыт.
- `mapLink` — точка BST в Google Maps. Пока пусто: показан район Чалонг без метки.
- `noindex: true` — сайт закрыт от поисковиков, пока это показ заказчику. Перед запуском рекламы поставить `false`.

Что нужно подтвердить у заказчика до запуска рекламы — в файле `ЧТО-ПОДТВЕРДИТЬ.md`.
